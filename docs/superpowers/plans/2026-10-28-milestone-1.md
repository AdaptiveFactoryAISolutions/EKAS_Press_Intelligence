# Milestone 1 implementation plan

> Execution: continuous implementation with TDD and focused parallel work for independent engine domains, followed by integration and fresh review. The completion charter authorizes execution without intermediate approval.

**Goal:** Deliver one reproducible governed synthetic press cell and an API-backed investigation product, with retained acceptance evidence.

**Architecture:** Unmodified pinned upstream submodules; external hybrid simulator reuses HistorianSim primitives. An OS-isolated diagnostic worker receives public evidence only. Formal pairwise discrimination, temporal benchmark matching, controlled verification, SQLite records and a same-origin UI complete the module.

**Stack:** Python 3.11+, HistorianSim, FastAPI/Pydantic, SQLite, vanilla accessible HTML/CSS/JS, pytest and Playwright.

**Spec:** `docs/MASTER_COMPLETION_CHARTER.md` and accepted original `docs/USER_CHARTER.md`.

## Constraints and review focus

- No access to or dependency on EKAS_Demo_UI; no upstream source changes.
- Exact eight charter diagnosis states. Synthetic data always labeled synthetic.
- Missing observation must produce ambiguity; no phrase-to-cause logic or hidden truth IDs in claims.
- Truth access denied by OS boundary, not naming or private Python attributes.
- Unavailable scopes/periods/signals are typed failures; no silent substitution.
- Incomplete evidence, duplicate submissions, disjoint time windows, rate/job changes and artifact-only events require adversarial tests.

## Shared interfaces

All cross-domain payloads use JSON-compatible dictionaries; typed API schemas validate their exposed boundaries. Times inside datasets are elapsed integer seconds with a UTC origin in context.

- `simulator.engine.simulate(seed=7, duration_s=86400, profile='sparse', events=None, repair_at_s=None) -> SimulationResult` exposes `.evidence` and `.truth` separately to the evaluator only. `evidence` has `samples`, `context`, `maintenance`, `quality`, `events` (observed operator/PLC records only). Each sample has `t`, signal values and quality metadata. Hidden schedules, class identifiers and physical states must not leak into evidence.
- `domain.catalog()` returns event dictionaries with `event_class`, `event_kind`, `asset`, `failed_item`, `failure_mechanism`, `symptoms`, `observable_signals`, `expected_directionality`, `timing_relationships`, `competing_causes`, `discriminating_signals`, profile observability and `verification_method`.
- `domain.signals()` returns signal metadata; `domain.profile_signals(profile)` returns signal IDs. `domain.assets()` returns relational assets. Pairwise discrimination definitions in public catalog are prior knowledge, not scenario truth.
- `observability.model.assess(available: list[str]) -> dict`; `sensor_gaps(available: list[str]) -> list[dict]` recomputes distinguishability for each augmentation.
- `rca.engine.investigate(evidence: dict, question: str = '') -> dict` consumes evidence only, outputs evidence provenance, hypotheses/alternatives/dispositions, state, qualification, action and KPI fields. No simulator imports.
- `benchmark.evaluator.score(truth: list[dict], claims: list[dict]) -> dict` matches intervals, item and mechanism, penalizes unsupported certainty/false positives, and reports each metric.
- `rca.verification.verify(before: dict, after: dict, action: dict) -> dict`; `financial.estimate(metrics: dict, assumptions: dict) -> dict`.
